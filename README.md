# BALO Mandarin — 當代中文課程 1

Interactive study app for **A Course in Contemporary Chinese (當代中文課程) Book 1**: flashcards, quizzes, listening practice, dialogues, grammar notes and handwriting practice — with Vietnamese/English meanings, pinyin and audio. Optimized for iPad and phones.

Ứng dụng học tiếng Trung theo giáo trình **當代中文課程 1**: thẻ từ vựng, trắc nghiệm, luyện nghe, bài đọc, ngữ pháp và luyện viết — có nghĩa tiếng Việt/Anh, pinyin và âm thanh. Tối ưu cho iPad và điện thoại.

- **Học sinh / Students:** `index.html` — enter class code + student code once.
- **Giáo viên / Teacher:** `teacher.html` — password-protected class statistics.
- **Thống kê / Statistics backend:** `apps-script/Code.gs` (Google Apps Script bound to the teacher's Google Sheet).

Textbook audio and content © their respective publishers; for classroom study use.
